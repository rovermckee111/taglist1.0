# CALL IN DA BIN

CALL IN DA BIN is an installable iPhone web app with ten fixed QR codes. Give each code its own user-named list and print one code at a time or a full sheet. Scanning a code opens its numbered list on the same device.

## Run it on iPhone

Publish these files to a static HTTPS host, then open the HTTPS address in iPhone Safari. Tap **Share → Add to Home Screen** to install it. The camera scanner loads from a public CDN, so its first use needs an internet connection.

Lists are saved in that browser on that device. There is no account or cloud sync, so the QR codes open the saved lists on the device that created them.

## Features

- Ten persistent, numbered QR codes.
- Name and edit your own list for each code.
- Add items and check them off.
- Print one QR code or a sheet of all ten.
- Scan a printed code to open its list.
