# CALL IN DA BIN

CALL IN DA BIN is an installable iPhone web app with ten fixed QR codes. Give each code its own user-named list and print one code at a time or a full sheet. Each QR opens the hosted app at its numbered slot. To open a list saved locally on the iPhone, scan its printed code using the app’s Scan tab. Each code’s distinct color marks its matching list.

## Run it on iPhone

Publish these files to a static HTTPS host, then open the HTTPS address in iPhone Safari. Tap **Share → Add to Home Screen** to install it. The camera scanner loads from a public CDN, so its first use needs an internet connection.

Lists and items save to local browser storage as you edit, so closing and reopening the app on that device should retain them. There is no account or cloud sync, so the QR codes open the saved lists on the device that created them.

## Features

- Ten persistent, numbered QR codes with distinct matching colors.
- Name and edit your own list for each code.
- Add items and check them off.
- Print one QR code or a sheet of all ten.
- Exit list setup without creating a list.
- Scan a printed code from inside the app to open its local list.
