# CALL IN DA BIN

CALL IN DA BIN is an installable iPhone web app with ten fixed QR codes. Give each code its own user-named list and print one code at a time or a full sheet. Each QR opens the hosted app at its numbered slot. To open a list saved locally on iPhone, scan its printed code using the app’s Scan tab.

## Install on iPhone

Open the hosted HTTPS address in Safari, tap **Share → Add to Home Screen**, then open CALL IN DA BIN from its Home Screen icon. Lists and items are stored on that iPhone in the app’s local browser storage.

Safari and the installed Home Screen app keep separate local lists on iOS. To transfer existing lists, open CALL IN DA BIN in Safari and tap **Export lists**. Save the backup file to Files. Then open the Home Screen app, tap **Import lists**, and choose that file. Existing QR slots are preserved; occupied slots are skipped rather than overwritten.

## Features

- Ten persistent, numbered QR codes with distinct matching colors.
- Name and edit your own list for each code.
- Add items and check them off; changes save locally as you make them.
- Print one QR code or a sheet of all ten.
- Export and import local list backups between Safari and the Home Screen app.
- Scan a printed code from inside the installed app to open its local list.
